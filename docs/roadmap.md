# Roadmap

Current scope is a small reusable source plugin. Work is prioritized by reproducibility and explicit contracts.

1. Build this extraction independently on UE 5.8.3 and record exact compiler/SDK results.
2. Add small clean-host health/sight validation fixtures using only redistributable source.
3. Replace project-specific montage paths with configurable soft references.
4. Make optional combat contracts easier to configure and document failures without bundling third-party content.
5. Verify host input ownership, component teardown, cooking and single-player edge cases.
6. Add reproducible examples and issue templates as real external use develops.

Networking, a complete game, vendor asset distribution and claims of established OSS adoption are outside the current delivered scope. Program applications should follow verified project facts; they do not change the implementation's validation status.
